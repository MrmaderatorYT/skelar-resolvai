# Action engine — policy decides, executor acts

Turns features + billing context into concrete actions (cancel, refund full/partial/goodwill/duplicate, pause, extend access, store instructions, evidence pack) and an execution mode: auto, suggest (1-click human approval) or escalate.

**Who uses it:** support agents, support lead, product team.

**Main metric:** 0 unsafe auto-refunds; share of tickets resolved without a human; refund ≤ payment amount always.

**Status:** MVP (hackathon, 31.10.2026).

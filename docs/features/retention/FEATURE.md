# Retention — one fair save offer, honest cancel for everyone else

When a customer asks to cancel for a reason we can fix (too expensive, no time, not using), Defuse makes **one** offer — 25% off for 2 months or a 2-month pause — but only if the customer is eligible. Everyone else gets an immediate, honest cancel. Anti-abuse rules stop discounts from going to everyone.

**Who uses it:** support agents, retention/CRM lead, finance (discount cost).

**Main metric:** save rate among eligible customers vs the holdout group; 30-day retention after a save; discount cost.

**Status:** MVP (hackathon, 31.10.2026).

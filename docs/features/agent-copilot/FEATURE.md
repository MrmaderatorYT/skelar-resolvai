# Agent copilot — one screen, one click

Gives the human agent everything on one screen: the ticket with highlighted evidence, the real goal, risk, billing facts, the proposed actions with reasons, and a reply draft in the customer's language. Approve executes; Escalate hands off.

**Who uses it:** support agents, support lead, product team.

**Main metric:** Time to resolution (AI median seconds vs baseline hours); approval rate of suggested actions.

**Status:** MVP (hackathon, 31.10.2026).

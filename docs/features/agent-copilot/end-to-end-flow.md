# End-to-end flow — agent-copilot

1. Agent opens a ticket from the queue.
2. Sees highlighted quotes (sarcasm, threat), intent and real goal.
3. Customer panel: plan, LTV, last charge, sessions since charge, abandoned cancel flow, refund history.
4. Decision card: actions, amount, reasons, money at risk.
5. Reply draft (Claude Sonnet 5.5 in live mode, templates in gold mode) — editable while pending.
6. Approve → executor runs remaining actions, reply saved, status resolved.
